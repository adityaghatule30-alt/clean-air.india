# 🌤️ CleanAir India

> A playful weather & air-quality app that turns boring weather data into something you actually want to check. 😂

## 🌐 Live Demo

👉 [**Open CleanAir India**](https://clean-air-india-ouoopoo4n-adityaghatule30-8513s-projects.vercel.app)

## ✨ Features

- 🌡️ Weather information
- 🫁 Air quality & AQI
- 📍 Location search
- 💬 City Group Chat
- 🌍 City Battle
- 🎮 Hotter or Not? game
- 🎲 Surprise Me
- 😂 Context-aware weather humor

## 🛠️ Built With

- React
- Vite
- Tailwind CSS
- Open-Meteo Weather API
- Open-Meteo Air Quality API

## 💡 About

CleanAir India combines real weather and air-quality data with a playful,
interactive experience.

Because checking the weather shouldn't feel like reading a spreadsheet. 😭
